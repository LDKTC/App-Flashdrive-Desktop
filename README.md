# App-Flashdrive-Desktop (FlashdriveHome)

หน้าโฮมแบบแท็บเล็ต Android สำหรับแฟลชไดรฟ์: แสดงไอคอนแอปทั้งหมดในไดรฟ์ กดเพื่อเปิด มีช่องค้นหา และแอปแกลเลอรีในตัว

## ใช้งานบนแฟลชไดรฟ์ (Windows)

1. คัดลอก `FlashdriveHome.exe` ไปไว้ในแฟลชไดรฟ์ (ไว้ที่ไหนในไดรฟ์ก็ได้)
2. ดับเบิลคลิกเพื่อเปิด แอปจะสแกนทั้งไดรฟ์ที่ตัวมันอยู่

- **แอป**: ไฟล์ `.exe .lnk .bat .cmd .url .AppImage .app` ที่อยู่ลึกไม่เกิน 2 ชั้นโฟลเดอร์ (ไม่แสดงตัวติดตั้ง/ถอนการติดตั้ง)
- **แกลเลอรี**: รูป `.jpg .png .gif .webp .bmp` ทั้งไดรฟ์ (ลึกไม่เกิน 6 ชั้น) กดดูเต็มจอ เลื่อนด้วย ← → หรือปัดนิ้ว, Esc = ย้อนกลับ
- **ไฟล์**: เปิดไดรฟ์ใน File Explorer

## พัฒนา

```
npm install
npm start -- --root=E:\     # เลือกโฟลเดอร์ที่จะสแกน (ค่าเริ่มต้นตอน dev = โฟลเดอร์โปรเจกต์)
npm test                    # ทดสอบตัวสแกน
npm run dist                # สร้าง dist/FlashdriveHome.exe (portable)
```
